# Version-cost candidate: source review only

This is a prepared research harness, not a software release or permission to run the real study.
The fixed candidate compares three original-byte archive workpoints, six role orders,
18 independent libraries and 648 serial update/history-validation/cold-read processes.
Private input catalogs, requests, results and admission records are NOT in this source packet.

The current admission remains closed. A real run requires an externally bound package/plan,
explicit human/window/budget authorization, a final source/protocol/input freeze and successful
CI for that exact source. The original1800-second budget and proposed3600-second revision
must not be confused; neither duration guarantees completion. Every task requires a fresh
bounded official preflight. Hash chains require an externally trusted initial digest.

CI uses synthetic metadata and a tiny fresh one-version full-archive fixture only.
CI does not call the quota service, any model/provider, fetch data, run the real12 trajectory,
or publish a version. Native worker checks must pass on Windows rather than silently skip.
Fixture directories are retained under the checked-out test-module directory; the runner
lifecycle, not a recursive-delete test helper, disposes of the workspace later.

API timing excludes external output copying and audit; default internal verification remains.
Independent history validation, endpoint inventories, guard and parent costs are separate.
Endpoint equality cannot exclude transient writes, hostile concurrency or power loss.
Logical application bytes are not physical IO, payload bytes are not RSS, and overlapping
parent/child intervals are not additive. Unknown resources remain unknown.

This study cannot establish NLI/answer quality, scientific reasoning or human long-session
benefits. No real performance has been scored by this source review packet.
