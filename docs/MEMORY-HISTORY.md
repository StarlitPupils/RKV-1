两组独立实验，不混称同一种科学证据：

1. QASPER官方dev v0.1/v0.2/v0.3原始文件，分别281篇论文，原文件名和所有字节保留。
   选dev是为本地CPU三轮可重复测量，非按压缩结果选择。来源/归档与成员SHA沿用
   version_data.py固定清单，未重写JSON或将三个版本假装为论文正文修订。
2. 2048条确定性SciFact结构控制记录及四条note，初始＋100更新。完全合成，专测
   长期累计差异与检查点边界，不算科学数据或真实发布。

QASPER新增字节适配：locator覆盖原始JSON成员的key、冒号和值，UTF-8字节偏移
通过不重叠片段增量计算；单独成员可重读恢复ID。只投影title、abstract、full_text
段落；qas问题/答案/标注与figures/tables不进入FTS或模型证据句子。全部原始字段、
空白、转义、文件外括号/逗号均仍在CAS原样保留。未知JSON模式、重复key、截断和
非法成员拒绝。kind=qasper-json-member-v1；源文件64MiB、单记录1MiB原型上限不变。

三次发布的论文投影文本相同；原成员变更分别281/9条（标注/元数据等），原文件名
每次变化。以此验证真实数据集发布负载，不推导科学文本修订或新问答质量收益。
文件名不改为统一别名，路径变化按现行v3规则计upsert，可能触发完整检查点。

Zlib6、同一冻结Rust扫描库、同份源和标签。保留全部CAS对象、索引、overlay和清单，
不GC，不共享不同条件的物理文件。每条件三轮新库/工作进程，20261022+round随机
