# v0.22 v4查询准备消融（结果前冻结）

目标：在v0.21原封不动的库上，验证批量重绑定校验及仅命中定位投影是否降低查询
准备成本。默认库仍预算v3，v4显式候选；物理归档v1–v6、CAS1、记忆v1/v2/v3/v4
及writer策略/持久字节均不改。不是新压缩或提交吞吐实验，不做模型请求。

诊断先在既有固定/v4末版运行64题cProfile，定位view/replay及SQLite准备路径；
这是工具扰动下的定位证据，非正式延迟/端到端加速，不能相加嵌套累计时间。原始
诊断摘要可随结果公开，只有函数名称/计数/耗时，无问题原文；全部正式方案先冻结。

实现：沿用每次查询的完整基础索引/overlay SHA、快照/源树身份验证。全部重绑定
仍在MATCH前校验，包括不会命中的记录，最多4096条、每批256个key查询基础key/
kind/投影SHA。拒绝缺失/摘要不符/重复/操作交叉，保留位移区间计数/非负/不重叠
检查。将已验证的新locator保存在请求内映射，返回命中时应用，不写SQLite定位表。
仅重绑定/位移overlay直接查询只读基础，不复制SQLite；有FTS删除或upsert时仍复制
并完整重放、保持全库BM25。当前命中继续验证CAS stored/raw、原记录SHA、key/kind
和完整投影SHA；没有跨查询缓存、校验跳过或新物化索引。writer非deferred视图仍
完整应用定位，批量校验不改变发布内容。请求结束全部释放。

固定读取器对照：

* v021：实际已发布v0.21 wheel安装模块，49模块SHA必须匹配v0.21实验源码；原
  逐条校验/写定位，有任何overlay则复制SQLite。
* lazy-copy：当前源码的批量校验和命中投影，但有overlay时仍强制复制SQLite。
  无overlay不人为复制。此为进程内benchmark wrapper消融，不新增产品配置。
* lazy-direct：当前默认v4读取路径，仅FTS变化时复制，纯定位直接读基础。
* budget-v3：当前源码读取同轮v0.21保留的预算v3库，同来源SID/问题/原文；作为
  既有默认参考，不把v3和v4的持久索引不同成本混成纯代码加速。

复用results/v0.21.0的round0全部库与记录，六个根（3组×v3/v4）逐文件大小/SHA
须匹配原最终持久树；不生成新来源、提交、迁移或GC：

* official-fixed及official-gear：原始QASPER dev三发布，各3状态，每版281篇。
  正文相同，原路径/标注变化；不是独立论文真正文修订。
* synthetic-fixed：原160篇生成论文9状态，包含全体标注/改名/重排、混合正文/
  增删、33标题检查点、恢复、label别名及1条标注；不新增科学样本。

共15个状态×4方案×3轮=180新进程；各1预热排除。官方沿用64问题，合成16词项，
同组/轮各方案完全同顺序，共6336正式查询（4608官方既有问题重复、1728控制）。
每进程再对初始快照读4题，共720历史身份查询；合成108个原始快照未来词项探针
必须阴性。进程输入统一为预生成的相同小问题文件，不在worker中重新加载官方
JSON来选题；题目SHA/排序不变，但RSS不直接与v0.21不同输入加载方式历史数字比较。
执行顺序20261024+round随机，旧/新源码及原始库保持固定。worker不加载原生模块。

每进程前后整库逐文件大小/SHA不变，全部测完六个根再核对，并重开其全部30个
历史快照实例，核对全部源大小/SHA；含v3/v4重复实例，不等于新科学版本数。
所有正式/历史查询比较key顺序、BM25绝对差<=1e-10、title/sentences/完整当前
locator摘要，与同轮实际v0.21/v4及原v0.21已发布结果一致。v3源SID相同，原文
身份必须一致，不能只比较命中文档ID。报告各阶段中位/p95、逐题/轮配对速度比、
CPU、进程峰值RSS及启动总时长，不能只挑最多重绑定阶段。

query wall/CPU计完整search及资源释放；输入加载/整树核验/历史诊断不混入正式
query时间，进程总时长另列。RSS含整个worker与相同题目输入/完整性核验开销，不
称查询增量RAM。冻结的全部RKV Python模块/HTML按实际旧/新reader各计一次，
lazy-copy/direct/v3计同一套当前源码，未用模块也计；原库全部历史占用逐项保留，
Gear另计原v0.21生成库使用的整份DLL/native.json一次，但查询不加载该库。公共
Python/SQLite/OS、pyc、安装及文件系统元数据未全额分配，不称完整部署净压缩。
本版新代码成本单列；无新持久空间收益或提交性能结论。旧精确库随Release提供
用于重建旧fixture，与当前CI原生功能资产分开。

仅本机温缓存；新版本默认仍v3，v4保持显式。无真实正文修订、E3、多跳、长期对话、
