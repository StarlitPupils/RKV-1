# Selected-source evidence witnesses — v0.73 frozen candidate protocol

Status: candidate source/protocol only until exact CI, three formal workers, raw metrics/report, builds, actual Release assets/install and final proof have all completed. Default SDK/UI is unchanged. This is an owned mechanism experiment, not a new scientific-language benchmark.

## Claim and boundary

A selected set of explicit signed Horn axioms can provide an original-file derivation even when retrieval does not cover all eligible memory files. Existing full-source `SourceSetVerifier` remains strict. New `Witness` takes a pinned SID, one to eight distinct valid `.logic.jsonl` paths, at most 1 MiB selected source payload, combined 1024 records/64 rules, and work 0 or 100000. Metadata independently lists the ACTUAL full eligible universe (nine initial, ten updated sources); it is not bounded by selected payload, files, or RAM. Unsupported selected grammar and malformed eligible metadata reject. Budget underflow rejects before payload rather than manufacturing logical Unknown.

Output `RKVSELECTWITNESS1` contains original file DAG nodes and `support_evidence_found` / `opposite_evidence_found`, plus `selected_closure_complete`. **`global_verdict` is always null**, including full eligible selection and both witnesses. A false found flag means only no witness returned in this selection. This never means globally false, globally unknown, scientifically true, or no counterevidence elsewhere. Signed Horn is explicit monotone derivation without NAF or explosion; later counterevidence may change global classification without invalidating an original positive derivation under its cited axioms.

The engine reuses the existing bounded closure in an internal selection projection. The new certificate does not expose the old projection's source-set completeness as real snapshot completeness. The auditor first independently enumerates REAL snapshot metadata and verifies selection sizes/coverage, then reconstructs an internal selected-domain certificate for the existing independent original-file DAG/finite closure checker. Producer and auditor share the `Projection` adapter and schema constants; the implementation is not wholly independent or formally proved. Source citations retain the real SID/path/offset/length/SHA. Neither selected nor original bytes establish scientific truth.

## Fixed campaign, before execution

Three fresh processes, each exactly 26 cases, 12 minus-one preflight controls, 3 old full-source refusal controls, 10 tamper controls and 8 historical certificate equalities. Totals: **78 / 36 / 9 / 30 / 24**. Every worker timeout 600 seconds, zero retries. No replacing failed round, excluding cases, adjusting budgets, or selecting a best repeat. Every JSON/parent sidecar is exclusive-created. Same owned fixture repeated mechanically, not independent science samples.

Each worker first ingests the nine-source initial snapshot, evaluates 4 modes x work(0,100000) = 8 cases; appends the explicit negative `late.logic.jsonl`, ingests ten-source updated snapshot, evaluates same 8 plus 2 expanded-selection cases; then repeats 8 original cases at old SID after new HEAD. Four modes: basis two files/query `reach(a,c)`; facts only/query `edge(a,b)`; rules only/query `reach(a,c)`; basis/query `reach(c,b)` with explicit opposite witness. Expected flags in `selected_witness_fixture.cases` are explicit case gold, not derived from the engine. Expanded selection includes the late opposite: direct negative survives work0; completed selection has both witnesses. Original eight old-SID certificates must remain exactly equal.

One preflight minus-one per original mode per stage (12) must reject with zero application payload reads. Old full-source verifier sees nine/ten actual eligible files and refuses at its existing eight-file cap, without source reads; this is a contract control, not an output-equivalent performance baseline. Ten original-certificate falsifications: global claim, eligible catalogue omission, selected size, record SHA, record path, found flag, fake full coverage, extra verdict, bool work budget, and work0 false complete closure. All must reject.

H1: all 78 explicit expected flag pairs match and original-file DAG audits accept. H2: all global verdicts null, real universe metadata/selection bounds and returned-byte conservation pass, all 36 preflight/9 old-strict/30 tamper controls and 24 history comparisons pass. These are mechanical acceptance gates, not scientific NLI quality or production gains. No speed gate: read observer is ON in all cases; its overhead is not independently measured and reported wall/CPU cannot establish acceleration.
