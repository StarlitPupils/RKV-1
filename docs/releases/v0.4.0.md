# E2 独立数值数据与 CSV 反变换优化

CSV 列重排有体积收益，但 Python 反变换和整块重建使恢复/范围读取明显变慢。
本版补充独立天文、超导材料数据及热点诊断，并把逐单元 Python 索引改为列切片
和 zip 重建；保留数值词法、维度/长度、换行 map 和块哈希校验。格式仍为 RKV v2，
编码器与归档字节不变；默认 CSV 关闭，旧归档继续可读。

- 新增固定 ZIP/成员哈希的 HTRU2、Superconductivity 下载器及来源/许可记录。
- HTRU2 的 CR-only 原文保持原样，CSV v1 回退；不改换行来制造正结果。
- Superconductivity 保留数值特征和含化学式的原始文件，包含不适用块的回退成本。
- 冻结 v0.3 CSV 反变换作为独立 worker 内的对照，读取同一个归档；全部请求配对。
- 递归源码指纹涵盖实验基线子包；增加 wide-column 字面值、回退、ZIP 哈希/写入隔离测试。
- 新增 run_csv_trials.py、summarize_csv.py、函数 profile、完整原始样本和 CSV-TRIALS.md。
- 实验 ZIP 随附全部协议和复现脚本，执行需要安装 wheel 或使用源码包。

## 验证与结果

3 组输入、18 个条件；90 次正式完整恢复与 18 次预热恢复、15,360 次正式范围读取
及 1,920 次查询预热全部逐字节一致。每个归档先完整校验，旧/新对照归档哈希
一致；实验前后输入、递归实现指纹和归档未变。本地 44 项测试中 43 通过、1 因
Windows 符号链接权限跳过；发布前 CI 再测跨平台 Python/Zstd 和 Rust 骨架。

1 MiB、同 codec 比较，五轮中位数：

| 数据 / codec | CSV 归档节省 | 旧/新 CSV 恢复耗时 | 新 CSV/普通恢复耗时 |
|---|---:|---:|---:|
| Wine / Zlib | 4.62% | 1.21× | 6.68× |
| Wine / Zstd | 0.40% | 1.09× | 2.17× |
| Superconductivity / Zlib | 11.79% | 1.15× | 7.17× |
| Superconductivity / Zstd | 1.40% | 1.16× | 6.94× |

有实际变换的条件恢复速度提高约 9–21%（耗时减少约 8.6–17.1%）；Wine/Zstd 四轮更快，其余三项五轮更快。
超导材料条件峰值 RSS 增加约 1.5–1.9 MiB，说明列切片的时间收益有内存代价。
与本轮最小普通归档 Zstd 相比，超导材料最小 CSV 归档 Zlib 只额外省 3.49%，
恢复约慢 11.1 倍。仍未通过综合收益验收，CSV 保持可选；HTRU2 无实际变换，
多 10 bytes 头部，轻微时间差仅为对照波动。

## 边界与下一步

基线只替换旧 CSV 反变换，其余用本版共同代码；不能当作整版应用的跨版本加速。
热点 profile 只诊断一个实际变换块，三次 cProfile 的累计时间嵌套且受工具影响，
不能作为纯性能结果。范围读取每类别 32 次/轮，五轮 p95 估计较粗，不替代 v0.3
十轮/128 请求的评测。单机温缓存；冷缓存、跨机器、跨日、推理质量均未测。

正则词法验证与完整变换块重建仍是优化候选；本版没有 Rust 加速、模型或字典。
实验源码部署成本另记，完整 Python/共享原生依赖仍未摊入每个归档。数组、代码、
数学文本和 E3/E4 待开展；后续改善类型表示/块内访问，再验证真实版本序列与
共享块存储。README 更新总进度，旧 Release/tag 和实验记录保持不变。
