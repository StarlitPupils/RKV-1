# v0.17.0 · 多版本更新放大与基础相对定位

修复v0.16中短插入令几乎所有记录偏移变化、继而重建完整索引的问题。新v3索引以
单份基础相对差异保存每个快照，用偏移区间表示未改写记录的位置变化，不建立不断
增长的重放链。查询仍核验完整索引/overlay SHA、读取CAS原记录、使用全库BM25。
接入已有Gear-v1及Rust Gear扫描作为可选提交方式，不改CAS1/归档v1–v6。

## 冻结对照结果

实现和协议在d7de9e7冻结，5条件×3轮，每组11个连续快照。原始SciFact仍为5,183
摘要、8,307,875B。后续追加、等长修改、插入/撤销、删除为独立工作副本上的合成
控制，不代表真实版本家族或新科学质量。全部历史保留，无GC；所有提交仍全量读源。

## 正确性与兼容

8,070次正式查询、1,815次旧快照查询的key排序及来源身份均匹配同轮固定/v2，
BM25绝对误差<=1e-10。165个历史快照最终全部重开，核对当时整源文件SHA和大小。
初始188个独立科学主张排名与v0.16一致，重复/探针不算新增独立问题。本轮0次
模型生成，无新科学推理质量结果。派生回答仍隔离，不进入主证据索引。

新建库默认固定分块＋v3索引，Gear/Rust显式选择；已有v1/v2库继续原策略，无自动
迁移。v0.16不读新v3应用清单；归档v1–v6/CAS1兼容不变。v3累计非位置变更超过
基础记录25%或偏移区间超过256时仍建完整检查点；不是任意更新恒定空间/时间。
另修复只追加空白字节、索引记录未变时的发布，字节仍精确保留。

本机149项测试：148通过，1项Windows符号链接权限跳过；含12轮修订、区间交叉、
旧定位、检查点、损坏、空白字节、CLI Gear和Python/Rust等价。CI与实际发行资产
安装检查随Release核验公布。没有目录/卷/真实掉电验证、自动GC、长期对话、多跳、
E3神经压缩或形式化证明。原始数据、私有研究文档及密钥不发布。

## 精确复现与原生库

Release额外提供rkv1-measured-gear-v0.17.0-windows-x86_64.zip：原样保存参与正式
测量的旧候选DLL及native.json。它的源码提交为96be8d0，DLL SHA见native-resource.json。
本次CI新编译的Windows/Linux原生资产另行提供，只作功能/身份核验，不能冒充实测
二进制性能。原生资产只包含CSV/Gear内核，不是完整记忆或归档解码器。

```powershell
python -m pip install -e .
python -m rkv1 fetch data/scifact --dataset scifact
New-Item -ItemType Directory -Force data/memory-source
Copy-Item data/scifact/corpus.jsonl data/memory-source/corpus.jsonl
# 将冻结实测Gear资产解压到measured/，保留原native.json。
python -m rkv1 memory-init data/my-memory data/memory-source --chunker gear-v1 --chunker-backend rust --native-library measured/rkv1_core.dll
python -m rkv1 memory-add data/my-memory data/updated-source --chunker-backend rust --native-library measured/rkv1_core.dll
python -m scripts.run_memory_updates --out results/local-memory-updates --work .tools/local-memory-updates --native-library measured/rkv1_core.dll
python -m scripts.analyze_memory_updates results/local-memory-updates --test-log path/to/test.log --native-library measured/rkv1_core.dll --plot
```

memory-source为完整资料树，只放corpus.jsonl或明确支持的UTF-8文本，不含claims/gold。
索引自动用v3；省略Rust参数则用Python提交扫描，Gear模式按建库配置保持。模型
仍用本机环境变量配置，本实验不调用模型。离线分析的native-library参数只覆盖
本机文件位置，库/原始元数据SHA仍须与记录完全相同。
