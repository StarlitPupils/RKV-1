# v0.21.0 · 论文投影与精确原始成员定位分离

此前QASPER文件名/标注变化也算FTS更新，三次官方发布每版都写完整基础。本版新增
显式compact-projection-v4：对title/abstract/full_text段落的精确投影保存SHA，原始
成员字节变化而投影相同则只重绑定当前locator。命中仍从当前CAS读原成员，验证
原SHA、key/kind及投影SHA，返回当前SID/路径/偏移/长度；不返回基础原文冒充当前。
全部原始字段、格式字节及历史保留，无GC。新应用清单v4需v0.21读取器。

**空间收益伴随查询退化。v4保持显式候选，默认继续v0.20预算v3。**

## 使用与兼容

```powershell
python -m rkv1 memory-init path/to/new-memory path/to/evidence --index-profile compact-projection-v4
```

候选必须显式选，不自动迁移旧库/旧视图。默认仍固定64KiB/Python、预算v3；
memory-budget仍只适用于旧base-v3/预算v3，不将现有v4降级。v4配置version=4并保留
现行replay_budget：32累计FTS变化、256KiB原记录、2MiB逐次CAS工作，加25%/256
位移规则。QASPER同key/kind的投影完全相同时才重绑定，最多4096条；超过则完整
检查点。预算限制特定重放工作，不能保证总wall/RSS上限。projection= qasper-paper-text-v1
保留句子边界、顺序与完整字符，非token归一化；section_name/qas/图表仍不投影。

新应用清单/overlay4及基础projections表需v0.21；旧v0.20读取器明确拒绝，不能把
CAS不变称为新视图向后可读。旧应用清单1/2/3继续读写，归档v1–v6/CAS1不改。
现有演示HTML无改动，无新模型配置。Release提供wheel、源码、实验协议/记录、
当前Windows/Linux原生功能库及精确旧实测Windows Gear库，二进制身份分开。
原始科学输入/问答原文、私有研究文件不发布。
