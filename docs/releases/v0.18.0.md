## 复现与使用

原CLI不变，升级后已有v3库可直接读取，不需迁移/重建索引：

```powershell
python -m pip install rkv1-0.18.0-py3-none-any.whl
python -m rkv1 memory-search path/to/v3-memory "rare genetic variants"
python -m rkv1 memory-serve path/to/v3-memory --port 8768
```

先按v0.17冻结协议生成固定/Gear-v3两组11快照，并解压实际v0.17 wheel作参考；
源模块/持久树哈希须匹配，测量时保持不可变。新目标文件必须不存在，不覆盖旧结果：

```powershell
python -m scripts.run_memory_queries --out results/local-query --work .tools/local-query --reference path/to/unpacked-v017-wheel --fixtures path/to/v017-work
python -m scripts.analyze_memory_queries results/local-query --test-log path/to/test.log --plot
```

复现不需要模型服务。本机http://127.0.0.1:8768 是独立字节相同v3演示副本，25条
派生记录保留，0次新生成；演示根8474614B不是完整部署成本或正式计时数据。
