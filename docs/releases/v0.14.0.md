# 跨领域字节重排与代码/数学对照

复测既有字节重排在一个SAC地震样例与一个DCD分子轨迹上的成本，增加Python源码、
LaTeX数学文档对照，另保留已见ECG和噪声。完整原字节/路径/头/记录标志保留。
输入、矩阵、门槛于ff73852提交冻结后测量；没有新增算法、归档格式或语义编码。

六组各8条件、五轮，全部同v4容器、恢复显式files，含完整文件SHA、flush/fsync、
关闭、目录发布及重试等待。240次正式恢复、43,520次正式范围读取，另48次恢复
预热和5,440次查询预热全部逐字节一致。正式文件fsync请求320次，目录发布重试
20次、没有整次任务重试或删除失败样本。所有阶段/范围返回有追加JSONL日志。

按本矩阵每方法事后最小完整归档，加numeric.py全源1,431B一次：SAC净省26.16%，
DCD净省15.56%；两新科学输入共享源一次合计净省15.79%（受较大DCD主导）。
ECG27.30%为已见对照。Python/LaTeX/噪声无实际重排块、各最小归档仍多13B；
计源后分别增加23.49%/6.42%/0.55%，尝试压缩仍有成本。不称完整部署资源。

主验收2/8通过：DCD/Zlib/64KiB和1MiB，计源净省14.69%/15.36%，同步恢复配对
加速1.371×/1.308×，常驻p95为1.713×/1.407×，重开p95为1.196×/1.445×。
编码配对仅0.600×/0.595×，编码更慢；只证明同后端工作点，不能声称胜过全部
普通codec或全流程支配。无发布重试的3/4对诊断子集恢复仍快1.220×/1.330×，
不替代主五轮或当作独立复测。SAC未联合通过。未更改门槛或删除不利候选。

两个领域各一个公开分发测试文件；DCD含3,341原子与实际98完整帧，头部500帧
差异原样保留。文本是字节网格对照，不是AST/数学语义编码。不是严格盲测或大样本
跨域泛化。v0.12和本轮门槛的比较对象不同，不能由0/8→2/8推导版本升级。
八个ECG配置完整归档SHA与v0.10一致；本轮不与历史close恢复批次计算加速。

本机120项测试119通过、1Windows符号链接权限跳过，新增5项定向检查通过；冻结
候选Windows/Linux CI通过。标签由CI重测并生成资产，实际发布包另核验。
无新增数值DLL/Blosc/模型/字典。原生资产仍仅CSV/Gear，不用于本轮性能结果。
默认编码不切换；文件同步不等于目录/卷或真实掉电保证。温OS缓存五轮为描述统计；
冷缓存、跨机器性能、数值Rust、CAS+数值和E3/E4推理质量未测。
