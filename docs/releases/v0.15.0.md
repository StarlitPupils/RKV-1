# v0.15.0 · 首个证据记忆与模型回答闭环

本版实现资料CAS入库、SQLite FTS5/BM25检索、原记录SHA校验、模型判定、句子引用绑定、
派生回答写回及快照更新。提供CLI和仅监听127.0.0.1的中文演示页，HTML随wheel打包。
这是E4最小基线；E2继续保留现有候选，E3尚未实现。v1–v6归档和CAS1格式不变。

## 实际实验

冻结实现/协议提交 `864e43d079a2114dfdd859d35845ed18f32093be` 后执行。SciFact原始
5,183篇摘要共8,307,875B逐字节保存在CAS，索引不含claims或gold标签。188条有标注
主张各检索三轮，共564次正式查询；重复轮次不是独立样本。

| 检索深度 | gold文档宏平均召回 | 至少命中一份gold的主张 |
|---|---:|---:|
| @1 | 70.70% | 136/188 |
| @5 | 88.34% | 169/188 |
| @10 | 94.21% | 180/188 |

检索含完整索引SHA及CAS命中记录校验，本机温缓存中位43.58ms，p95 57.47ms。
冷缓存和跨机器未测；英文词法结果不代表跨语言语义召回。

用户指定的官方DeepSeek `deepseek-flash` API：关闭thinking、JSON模式、temperature0、
每次最多256输出token。12条预先确定的平衡dev主张×两条件，随机顺序、无重试，
真实生成请求24次。存储/检索在本机CPU，模型计算在远端。

| 条件 | 格式和引用绑定有效 | 标注判定正确 | 8条有证据主张引用完整gold依据 | 判定与完整依据同时正确 |
|---|---:|---:|---:|---:|
| 空证据 | 12/12 | 4/12 | 0/8 | 0/8 |
| top5检索证据 | 12/12 | 10/12 | 7/8 | 6/8 |

空证据使用同一个“仅据所给证据回答”的提示，全部判为证据不足；不是无约束闭卷
模型或成熟RAG对照。12条单次样本不能支持通用科学推理提升。公开dev数据可能已被
模型见过，远程别名/权重不可独立冻结；引用绑定也不是科学蕴含证明。

两条错误（ID3、48）均已召回gold文档并提供完整gold句子。ID3弃答且未引用；ID48
引用完整依据后仍判证据不足。保留全部失败，不修改已测提示或筛掉主张。

服务报告输入30,634、输出1,029，共31,663token；输入缓存命中1,408。实际账单未知。
模型回答作为派生记录保存，不能自升格为原始证据；索引损坏、原文损坏、越界/遗漏
句子引用、API失败均显式失败，无静默重试或伪造回答。

## 完整资源代价与边界

初始CAS、一个完整索引、清单及HEAD共19,319,447B（原文2.325倍）；保留两快照及
派生记录后35,728,598B（原文4.301倍），其中两个索引32,710,656B。没有整个记忆
系统的净压缩收益；运行时、文件系统元数据、远程权重和服务成本尚未完整分配。

合成UTF-8/CRLF记录验证更新、新实例重开、新/旧快照隔离及原字节，另用独立CLI
子进程复核。合成派生探针不能通过主证据检索。不是长会话、自动整理、冲突消解、
多跳、embedding/图检索、神经压缩或形式化验证。文件同步不等于目录/卷/掉电验证。

本机132项测试：131通过、1项Windows符号链接权限跳过；包检查另外验证实测45个
Python模块及HTML字节、安装后CLI、v1–v6兼容和旧读取器。发布CI和实际资产核验随
Release附加记录公布。原始语料、私有研究文档及密钥不进入发行包。

## 运行

```powershell
python -m pip install -e .
python -m rkv1 fetch data/scifact --dataset scifact
New-Item -ItemType Directory -Force data/memory-source
Copy-Item data/scifact/corpus.jsonl data/memory-source/corpus.jsonl
python -m rkv1 memory-init data/my-memory data/memory-source
python -m rkv1 memory-search data/my-memory "rare genetic variants"
$env:RKV_LLM_BASE_URL="https://api.deepseek.com"
$env:RKV_LLM_MODEL="deepseek-flash"
# RKV_LLM_API_KEY由本机安全环境配置，不写入源码或聊天。
python -m rkv1 memory-serve data/my-memory
```

打开 http://127.0.0.1:8765 。CLI也支持memory-answer、memory-add、memory-stat和指定
旧snapshot。每次手动回答会产生新的API请求；正式24次评测不会自动重跑。
更新时source代表完整的新资料树；保留旧快照及各自索引，暂不做索引去重。
