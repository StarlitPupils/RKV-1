# Rust 精确反变换与本机 CPU 配对

CSV 反变换仍占用恢复/短读取时间，本版将其数值字面量校验与列到行重建迁移到
可选 Rust C ABI 后端。保留字面量/换行/边界字节及原有所有哈希校验，不解析浮点数。
默认 Python、Zlib/1 MiB、v2、CSV 关闭；归档格式不变，读取兼容 v1/v2/v3。

- Archive/verify/unpack/read 支持实例级 decoder_backend 与显式原生库路径；
  相邻 native.json 核对大小、SHA-256、源提交与 ABI，失败直接报错。
- 26 份归档供两后端读取；普通编码/CSV、Zlib/Zstd、整块/16/64KiB 两层单元和
  HTRU2 CR-only 负对照保留。恢复/范围的条件、轮次与模式打乱，实际范围请求匹配。
- 记录完整恢复库加载/FFI/复制成本和独立 RSS；原生资源全额计费及摊销情景单列。
- 逐轮样本、归档/输入/源码/库指纹、来源、负结果、图与复现说明随版本保存。
- Release 提供 wheel、sdist、实验 ZIP、Windows/Linux 原生 ZIP；原生包记构建来源。

## 验证与结果

本地 63 项测试：62 通过、1 Windows 符号链接权限跳过。CI 增加两平台真实原生
后端的数值字面量差分、畸形输入、归档兼容/完整性与配对协议测试。
正式 260 次完整恢复 + 52 次恢复预热、99,840 次范围读取 + 6,240 次查询预热
全部逐字节一致；输入/源码/归档/原生库/元数据前后一致。

超导材料/Zstd/CSV，完整恢复 Python → Rust：1MiB 整块 427.17 → 91.94ms，
64KiB 单元 395.15 → 99.45ms，16KiB 单元 626.74 → 120.09ms；五轮配对恢复
加速中位分别 4.63×、3.97×、5.22×，全部五轮更快。整块重开 p95 从30.997降到
4.496ms，各轮 p95 的中位数；配对重开加速中位约7.02×。

普通 Zstd/整块恢复 61.08ms，仍优于相应 CSV/Rust。原生库+元数据121,747bytes：
最小超导材料 CSV/Zlib 归档比最小普通 Zstd 减小263,156bytes，计入一次原生资源
净省141,409bytes；恢复却为136.34ms，普通为61.08ms。Wine 单份归档不能抵消
原生资源，HTRU2 没有实际变换收益。优化不支持默认全局启用 CSV 或原生后端。

## 复现与范围

实验使用冻结 v0.5.0 Windows DLL，源码提交
5418b305172d349a864f64f123070e3ee949d301；csv.rs 与本版相同。SHA/编译器在
results/v0.6.0/native-provenance.json。复现选这份二进制；本版附的新构建有自己的
元数据，不能假定不同构建哈希相同。说明见 docs/NATIVE.md。

恢复含库身份检查/加载、FFI、复制、codec与哈希；预热范围请求不含首次进程加载。
共享 Python/系统/链接运行时尚未完整分配，不称为完整部署成本。范围 RSS 含
真值和工作账本读取器，不当作生产 RSS。单机温缓存、五轮描述统计；冷缓存/
跨机器/跨日和推理质量未测。没有原生 encoder/codec/hash 或多版本 CAS 的结果。
