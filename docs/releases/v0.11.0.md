# 浮点原始字节与专业压缩基线

E2 从 int16 扩大到三个完整公开 FITS 示例：Spitzer/Bolocam float32 与 MSX float64。
全部头、图像、填充、NaN payload 保留，原文件共 3,939,840 B；复测原 PTB ECG
1,154,687 B，另用固定 262,147 B 噪声作回退负对照。没有浮点转换/量化或端序修改。
三个天文示例来自同一托管项目，不是三个独立科学领域；Bolocam 约 5% NaN。

## 实现和兼容

新增可选 scientific extra，固定 python-blosc1.11.4 与 zstandard0.24.0，使用 bytes API，
不使用 NumPy API 或裸指针。C-Blosc/Zstd 单线程、clevel3、内部块 64KiB，提供
无过滤/字节重排/位重排，各 2/4/8-byte 类型宽度共九个显式 codec。
不是 Blosc2 或 NDArray 子块读取；仍恢复/校验整个外层 RKV 块。

专业 codec 自动写 v5 平块格式，字段沿用 v4；全部实验条件显式同 v5。
旧读取器拒绝 v5，v4 拒绝新 codec；v5 不支持 CSV/独立单元/叠加外层数值变换。
默认 none/v2、数值策略/v4、单元/v3、CAS1 不变。
解码先核对帧版本/宽度/codec/过滤标志、精确压缩/原始长度及块上界，再调用
C 库结构验证与受限 bytes 解码，最终验原始 SHA；保留 manifest/块/文件哈希、
完整恢复比对及 flush/fsync 发布语义。未加入数值 Rust 内核。

## 五轮实测与资源成本

每组 18 条件：64KiB/1MiB ×（Zlib6/Zstd3 ×普通/Python重排/XOR，及三种Blosc过滤）。
完整编码/恢复各新进程，计首次 Blosc 导入/设置；范围读在查询预热后正式计时。
所有条件/生命周期请求一致，条件/轮次打乱。原始记录包含 wall/CPU/峰值RSS及
所有请求/延迟样本。450 次正式恢复、86,400 次正式范围读取，另 90 次恢复预热、
10,800 次查询预热全部逐字节一致；归档确定性、源/源码/整份依赖身份核对通过。

| 输入 | 最小普通归档 B | Python重排归档 B / 加源后净省 | 最小Blosc过滤归档 B / 已安装情景节省 |
|---|---:|---|---|
| Spitzer | 1,838,171 | 1,631,953 / 11.14% | shuffle 1,649,920 / 10.24% |
| Bolocam | 1,455,509 | 1,333,725 / 8.27% | shuffle 1,358,357 / 6.67% |
| MSX | 109,110 | 92,840 / 13.60% | bitshuffle 94,400 / 13.48% |
| ECG | 865,389 | 627,711 / 27.30% | shuffle 650,199 / 24.87% |

限本次矩阵内按体积各自选参，不是按速度选择或全局最优。不同后端 Zstd 版本、
级别映射与分块不同，不将跨后端差异归因于单一过滤器。
资源账本包括完整已安装 Blosc 包 4,876,827 B（含未用 codec/元数据）+适配源 2,690 B，
合计 4,879,517 B；隔离环境没有 NumPy。Python 变换计 numeric.py 1,431 B 一次。
四组科学输入均用 Blosc shuffle，共用依赖一次：归档合计少 11.99%，但加资源后
8,635,860 B，比最小普通合计 4,268,179 B **多 102.33%**。依赖已安装情景另列，
不把这份库成本藏入背景。Python shuffle 四组加源一次净省 13.60%。
公共 Python/core/Zstd/OS 未全额分配，这些情景不称完整部署大小。

完整恢复计首次加载后，三个 FITS 的最小 Blosc 过滤归档均慢于最小普通归档。
仍有同后端有利工作点：ECG/Blosc/64KiB 位重排相对无过滤，归档少 22.59%，
编码/恢复/常驻p95/重开p95逐轮配对中位 1.27×/1.10×/1.43×/1.27×，均5/5轮更快。
五轮只作描述统计，不给显著性/跨机器稳定性结论。XOR 恢复成本较高，bitshuffle
不是普遍最省；噪声所有条件回退raw，仍付顶层标签和编码尝试成本。默认保持不变。

Python3.10/3.13 和既有 Rust CI 已通过，tag 发布以 CI 再次通过为门槛。

发行包另验离开源码目录安装、已发布 v0.10 读取器的 v2/v3/v4兼容和v5拒绝、
新CLI完整恢复/范围读取、所有实测源码字节与wheel/sdist/tag一致。

独立环境/运行步骤见 docs/SCIENTIFIC.md，结果/配对/CPU/RSS/资源身份与图见
results/v0.11.0。公开数据固定URL/commit/SHA，来源与署名见docs/DATASETS.md；

不是本轮Blosc依赖；本地wheel SHA与CI ZIP SHA分开，实测源码必须一致。

推理质量结果。E2未全部完成，E3/E4待开展。下一步按资源成本与读取工作点缩小
类型/布局候选，再按热点证据决定自有数值内核是否值得原生化。
