# 受控 E0 基准与 E2 可逆 CSV 初步试验

首版将整流 TAR 与分块 RKV 对比，容器、校验、落盘及缓冲方式不同。本版加入同容器
对照，检验 codec、块大小、去重及可逆类型变换各自的收益。

- RKV v2 支持 Zstd 3、Zlib 6、raw 和去重关闭；全部模式采用相同 SHA-256 校验、fsync 与原子发布。
- 新读取器兼容 v0.1.0 归档；以首版真实生成的固定 fixture 验证。新归档需 v0.2.0+ 读取器。
- 64 KiB / 256 KiB / 1 MiB 扫描；编码、恢复、随机读取各在独立新进程测内存。
- 按文件字节数加权抽样，并分别测大小文件、跨块窗口、已打开与重新打开清单。
- 扩展 QASPER 43 MB 科学论文数据、Wine red/white；五组输入、102 配置。
- 增量涵盖最大文件追加、中间插入、等长替换、重命名及最小文件删除。
- E2 数值 CSV 列重排完整保留数值原文、表头、换行及边界字节；变换不适用或块收益不足时回退普通编码。
- 原始样本、输入 SHA-256、源码指纹、运行时占用、摘要、图形与复现脚本随版本保存。

## 测量与结果

每配置 1 次预热、5 次完整记录；每种可用查询类别 128 次，分别测两种打开方式。
正式恢复 560 次、预热恢复 112 次、范围读取 75,264 次均通过逐字节比较。
本地 33 项单元测试中 32 通过、1 因 Windows 符号链接权限跳过；CI 再运行跨平台
Python 与可选 Zstd 测试，以及 Rust 骨架测试，通过后发布。

1 MiB、同容器、去重开启、无变换：

| 输入 | Zlib 归档 bytes | Zstd 归档 bytes | Zstd 节省 |
|---|---:|---:|---:|
| SciFact | 2,863,283 | 2,745,550 | 4.11% |
| QASPER | 10,902,467 | 10,660,769 | 2.22% |

Zstd 在上述科学文本上更快；具体中位数、方差、分层 p95 和内存见附件 SUMMARY.md/JSON。
UCI/Wine 上 Zlib 更小，不能将某个 codec 宣称为全部数据上的最佳。

CSV 列重排在 Zlib 上净归档节省约 4.6–4.7%，但 Python 解码与范围读取开销明显增加，
因此默认关闭。真实语料尚无固定块去重收益；合成重复仅验证机制。
同流式容器下内存更接近，修正首版把整流缓冲差异视为固有 codec 优势的潜在解读。

## 边界与下一阶段

这是单机、温缓存、后台负载未隔离的 prerelease。重新打开不代表冷磁盘。归档字节
不是完整部署占用；额外 Zstd distribution 约 1.13 MB，共享代码和变换模块另记成本，
Python/全部共享原生依赖尚未分摊。本版没有外部模型、字典、语义索引或推理质量结果。

E2 目前仅数值 CSV 原型，数组、代码和数学文本仍待开展；Rust 尚未接入性能路径。
旧 Release/tag 与结果保留。附件提供 wheel、源码包和完整实验记录 ZIP。
