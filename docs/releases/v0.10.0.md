# 精确数值字节原型：重排、XOR与完整成本

E2新增2/4/8字节宽度的显式`byte-shuffle-W-v1`、`xor-shuffle-W-v1`策略，
不解析浮点、不量化或改端序，尾部残字节保持原样；XOR预测在每块重启。
数值策略自动写**新v4平块归档**，旧读取器拒绝v4。v0.10继续恢复v1/v2/v3，
默认none仍写v2，现有CSV、独立单元及CAS格式不变。默认不启用数值变换。

v4字段沿用v2但仅允许none与上述数值标识；`coded_size==raw_size`，至少两个完整字。
保留manifest/块/文件SHA、有界单帧解压、整块/文件恢复验证与逐文件flush/fsync。
不支持v4独立单元或CSV。数值原型为Python，已有Rust CSV/Gear库不提供数值加速。

## 实验范围和验证

两个数据库各一条原始int16记录：EEGMMIDB 1.0.0 S001R01完整EDF+ 1,275,936bytes；
PTBDB 1.0.0 s0010_re的dat/xyz/hea合计1,154,687bytes。原始相对路径、头、注释、
换行和全部字节保留，不重采样或转CSV/NPY。另有262,147bytes固定种子噪声负对照。
官方来源/引用/ODC-By1.0许可见仓库docs/DATASETS.md，每文件SHA随结果固定。

每组12条件：Zlib6/Zstd3 ×64KiB/1MiB ×none/重排2/XOR重排2；全部同v4容器。
五轮正式编码/恢复，条件/轮次随机打乱；独立进程分阶段测wall、CPU及RSS。
范围五轮常驻/重开模式，32正式+4预热请求/非空类别；实际请求指纹全匹配。
正式**180次完整恢复、34,560次范围读取**，另36次完整预热、4,320次查询预热
全部逐字节一致。各轮完整归档和选择账本一致，源码/输入/读前后归档哈希保持不变。

本机90项测试：89通过、1 Windows符号链接权限跳过。新增位模式测试包含2/4/8字宽、
端序、NaN payload、signed-zero、Inf、subnormal和残尾；另测错误配方、损坏基底、
原始SHA失败、未对齐块、局部读取、重复数据和版本拒绝。浮点位模式测试不等于
真实浮点科学数组性能评测。候选Windows/Linux CI已通过，tag发布仍以CI为门槛。

## 完整成本与性能取舍

本次候选集合内按完整归档体积各自选最小普通/策略参数，不按速度挑选。
包括prefix、JSON、路径、文件/块SHA、变换标识及payload；另对每个候选全额加
numeric.py原始源文件1,431bytes，作为保守独立计费情景。同版本安装已包含该模块；
没有新增DLL、权重或字典，公共Python/core/codec/pyc和物理目录未全额分配。

| 原始记录 | 最小策略参数 | 完整归档 bytes | 加源后对最小普通净节省 | 编码/恢复 ms |
|---|---|---:|---:|---:|
| EEG普通 | Zstd/1MiB/none | 682,548 | 基线 | 14.268/7.874 |
| EEG重排 | Zlib/1MiB/shuffle2 | 638,748 | 6.21% | 114.230/8.417 |
| EEG XOR重排 | Zlib/1MiB/xor-shuffle2 | 583,902 | 14.24% | 174.255/35.985 |
| ECG普通 | Zlib/1MiB/none | 865,389 | 基线 | 44.029/9.307 |
| ECG重排 | Zlib/1MiB/shuffle2 | 627,711 | 27.30% | 62.011/8.007 |
| ECG XOR重排 | Zlib/1MiB/xor-shuffle2 | 636,268 | 26.31% | 120.620/32.224 |

EEG的XOR更省空间，但恢复中位约为最小普通的4.57倍；ECG中XOR比单纯重排更大且
更慢。所有真实记录候选对相同codec/块大小的编码配对均0/5轮更快，选择过程本身
要做普通和候选两次压缩。不能将原型描述为综合全面获胜。

ECG/Zlib/64KiB单纯重排是一个有利的读取工作点：归档减少26.90%，同轮恢复、
常驻p95、重开p95配对加速中位1.30×/1.97×/1.31×，均5/5轮更快；编码加速倍率0.657×（更慢）。
配对倍率逐轮相除后取中位，与两项耗时中位之比不同；五轮仅作描述，无显著性结论。
每个范围仍整块反变换/校验，大块压缩率改善不保证局部读取更快。

噪声12条件全部回退none，但策略头仍多12/13bytes，专用源另计，编码尝试仍有成本。
因此数值策略保持显式选择。本轮为独立归档，**未与共享CAS组合测量**，不能把本轮
节省百分比与v0.9跨版本共享收益相加或相乘。

```powershell
python -m scripts.run_numeric --out results/local-numeric
python -m scripts.summarize_numeric results/local-numeric
python -m rkv1 pack data/numeric/eeg eeg.rkv --codec zstd --chunk-size 65536 --transform byte-shuffle-2-v1
python -m rkv1 verify eeg.rkv
```

完整协议/格式在docs/NUMERIC.md；源、原始结果、CPU/RSS、逐轮配对、科学图和独立
验证在results/v0.10.0。本机原始数据不进入源码/实验发行包。
发布包核验中的本地wheel SHA仅指Windows本地构建，CI发布容器另有SHA，实测Python
源字节必须相同。新通用原生资产用于已有CSV/Gear，不是本轮性能依赖。

真实科学样本仅两个int16单记录，ECG相邻字可能来自不同通道；EDF注释和文本也参与
变换。未测真实浮点数组、通道重排、更广codec/专业科学压缩器、冷缓存、跨机器、
跨日或推理质量，不声称全局最优、完整部署成本或E2全部完成。
下一步扩大真实浮点/布局与专业算法基线，再按热点决定原生化；E3/E4仍待开展。
