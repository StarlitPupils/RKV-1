## 使用与兼容

新建库默认固定64KiB/Python分块和compact-budget-v3；Gear/Rust显式选。API可传
replay_budget，默认值是工程起点，非全局最优。旧策略可memory-init显式指定
--index-profile compact-base-v3；旧库不自动切换。旧v3库可执行：

```powershell
python -m rkv1 memory-budget path/to/existing-v3-memory
```

只原子更新未来writer配置，HEAD/旧清单不变，不重建旧慢视图。同输入/标签复用
原快照仍返回旧视图。仅允许旧base-v3/新budget-v3；不迁移旧v1/v2或完整重建策略。
配置非法/替换失败时保留原配置；单写者语义，未声称多写者事务或掉电目录持久。

归档v1–v6、CAS1、记忆清单v1/v2/v3格式均不变。v0.19可读取新v3预算视图；旧
writer不认识新profile，会拒绝且不推进HEAD，但旧实现可能已写入未引用CAS对象。
本版配置在CAS发布前验证。QASPER来源仍需v0.19+，投影/原始路径及标注耦合未解决。
旧v1/v2读写策略保持。打包HTML无改动，无新的本机模型服务/API费用。

Release含Python wheel/源码、完整协议与实验记录、当前Windows/Linux原生功能库，
另附正式测量的精确旧Windows Gear库（source commit 96be8d0），二者身份分开，
当前CI二进制不用于解释正式计时。私有研究报告和原始科学语料不发布。
