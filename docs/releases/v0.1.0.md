# E0/E1：首个可运行与实测版本

把原对话的无损存储草案实现为可安装 Python 项目，在本地 CPU 上实际运行测试及公开科学数据基准。

- 固定分块、跨文件 SHA-256 去重、Zlib/raw 自适应存储、完整解码与逐字节对照。
- Manifest 哈希、块/文件哈希、路径与尺寸校验；恢复全部验证后才发布目标目录。
- 随机范围读取；增量编码可验证并复用旧快照块，输出独立完整快照。
- E0 基准含 Zstd 3、Brotli 5、LZMA 6、Zlib 6、原始 TAR、RKV；1 次预热 + 3 次重复，记录原始样本、随机读、CPU 时间及进程峰值内存。
- 固定 UCI Iris/Wine Quality 与 SciFact 数据 SHA-256；另设合成跨文件重复对照。
- Python/Rust 项目骨架、格式规范、实验路线、执行说明和自动测试/发布工作流。

## 实验结果

在 Windows / i5-14600KF / Python 3.13.12 上，SciFact 原始大小 8,582,267 bytes：

| 方法 | 归档 bytes | 倍率 | 编码中位 ms | 恢复中位 ms | 随机读 p95 ms |
|---|---:|---:|---:|---:|---:|
| RKV1 | 2,862,790 | 3.00× | 335.69 | 37.69 | 3.35 |
| TAR + Zstd 3 | 2,670,268 | 3.21× | 43.29 | 16.80 | 9.43 |
| TAR + LZMA 6 | 1,967,480 | 4.36× | 3756.99 | 79.32 | 78.85 |

全部 3 组语料 × 6 方法的完整恢复及随机读验证通过。真实语料默认分块没有重复块，
不能宣称去重已提升真实数据压缩率。合成重复对照中 4 个引用只保存 1 个唯一块。
增量探针中 SciFact 复用 10/11 块，仍重新读取全部源数据并写出完整新容器。

本地 21 项单元测试：20 通过、1 因 Windows 无符号链接权限跳过；另由发布流水线运行
Linux/Windows 的 Python 3.10/3.13 测试和 Rust 骨架测试，通过后才发布本 Release。

## 限制与兼容性

Draft 0.1 新增 32 字节 manifest checksum，与原对话未发布草案不兼容。
这是研究原型 prerelease；Rust 只实现边界骨架，尚无 Rust 压缩加速。
随机读取比较采用已打开的 RKV 与整流 TAR，尚无 seekable Zstd 对照。进程内存包含
运行时和缓冲；共同运行时没有摊入归档字节。尚未实现 E2/E3/E4，也没有推理质量结论。

附件包含 wheel、源码包和完整实验 JSON/说明；README 提供运行命令与下一阶段路线。
