# v0.14 跨领域字节重排与代码/数学对照

本轮不新增编码算法或归档格式。先固定新领域输入和门槛，再验证既有全文件字节重排；
没有按新压缩结果选文件或调参数。仅做结构/尺寸与原始SHA检查后冻结协议与实现。

## 输入和边界

固定仓库提交与每文件SHA见rkv1/crossdomain_data.py；完整仓库相对路径保留：

- ObsPy 1.4.2 的CRLZ.HHZ.10.NZ.SAC，131,704B；固定树中最大的.sac，按尺寸选，
  632B头及32,768个little-endian float32样本。不是完整地震数据库。
- MDAnalysis 2.9.0 的adk_dims.dcd，3,931,724B，典型公开测试轨迹，3,341原子。
  原头声明500帧，但实际文件保存98个完整三轴帧；差异不修复、不重写。完整分发
  文件不是完整原始模拟运行，不能按头部500帧计算压缩分母。
- SciPy v1.15.3 完整rk.py，22,800B；LaTeX amsmath完整testmath.tex，81,184B。
  两者是非数值字节网格对照，不执行/编译，不代表实现了AST/数学语义编码。
- 已见PTB ECG三文件与固定噪声作连续性/回退对照，不算新增验证语料。

新科学输入各仅一份，来自不同项目与领域；仍是公开样例，没有严格盲测或大样本
泛化保证。源许可、原头与署名保留，原始科学/源码/TeX输入不进入发行包。

## 预定矩阵和成本

六组各8条件：Zlib6/Zstd3 ×64KiB/1MiB ×none/byte-shuffle。ECG字宽2，其余显式
字宽4；包括头/记录标志/文本在内的完整字节网格，不新增语义路由。均为同v4容器。
每个块先尝试普通codec，重排只有局部payload收益超过标识成本才选择；顶层标签
仍可能使完整归档增大。保留全部失败候选，不按结果删除文本/噪声对照。

每条件一次完整预热，五轮正式。每个数据集内部的配置/轮次打乱，数据集顺序固定，
不声称跨数据集交错或隔离系统负载。种子20261017。每阶段新进程，记录wall/CPU/RSS。
恢复显式files：完整文件SHA验证后flush/fsync/close，再发布目录，所有策略相同。
发布有界重试等待计入时间；不重试fsync或整次任务。API计时排除Python进程启动、
外部逐字节比较和删除输出；编码含普通与候选两次压缩尝试。工作区E卷scratch，
不是默认C卷TEMP。所有输出与原文件逐字节比较，每轮归档SHA一致。

范围读取五轮、常驻/每次重开两模式，每个非空类别32个正式请求和4预热。类别为
byte_weighted/small_file/large_file/cross_chunk，空类别保留但不计数。跨块请求用
64KiB网格，不一定跨1MiB块；各配置与模式在同轮使用同一请求指纹。预读归档，
温OS缓存、无解码缓存。p95是每轮p95再取中位，配对加速先逐轮ordinary/candidate。

完整归档包含路径/清单/块/文件SHA/索引/标识与payload。候选另分配整个numeric.py
源1次（当前1,431B），即使回退也计。分别报告每组计一次、两新科学输入共用一次。
公共Python/core/Zstd/pyc未全额分配，不称完整部署大小。无新DLL/模型/字典，不使用
Blosc、ObsPy或MDAnalysis运行库进行编码/解码，诊断扫描只在计时外记录原始结构。

## 验收与审计

每个同codec/块长工作点：候选归档+专用源不得大于普通归档，完整恢复、byte_weighted
常驻p95及重开p95的配对加速中位均>=1，各至少4/5轮更快才通过。编码另列，不能
据此宣称全流程支配。两个新科学输入共8个主验收工作点；已见ECG与文本/噪声结果
另列，不混入主验收通过率。各方法事后最小归档只是本矩阵内按体积选参的情景。

追加JSONL日志保留每阶段返回、外部真值验证和范围返回；在计时外flush/fsync。
失败直接停止并记录，不覆盖已有结果目录、不自动重跑任务。日志与最终汇总独立
核对；若整轮中止，先披露已有阶段和原因，再另冻实现，不丢弃失败选择好结果。
正确性/来源/源码/资源冻结与范围请求、工作量均核对。五轮为描述统计，不给显著性
或跨机器承诺。v0.13及以前原结果不覆盖，不跨历史同步策略批次计算加速。
目录/真实掉电/冷缓存/跨机器性能、数值Rust、CAS+数值及E3/E4推理仍未测。
